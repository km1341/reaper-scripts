# km1341's REAPER 脚本

[English](README.md) | [中文](README_CN.md)

一套 REAPER Lua 工作流自动化脚本，通过 [ReaPack](https://reapack.com/) 分发。

## 安装

### 通过 ReaPack（推荐）

1. 打开 REAPER → 扩展 → ReaPack → 管理仓库
2. 点击 **添加新仓库**
3. 粘贴以下 URL：

```
https://raw.githubusercontent.com/km1341/reaper-scripts/main/index.xml
```

4. 点击 **确定**，然后浏览包列表查找并安装脚本。

### 手动安装

将 `.lua` 文件复制到 REAPER Scripts 文件夹：

- **Windows**：`%APPDATA%\REAPER\Scripts\`
- **macOS**：`~/Library/Application Support/REAPER/Scripts/`

然后通过 **操作 → 显示操作列表 → 加载...** 加载

## 脚本

### 从选中项目批量创建区域标记

**文件**：`km1341_Items_to_Regions.lua`

为每个用户选中的媒体项创建一个区域标记。适用于**任何项目类型**——音频、MIDI、视频等。

**特性**：
- 适用于任何选中的媒体项类型（音频、MIDI、视频等）
- 每个选中项创建一个区域标记
- 使用 Take 名称作为区域标签（无名称时回退到 `Region_001`、`Region_002`...）
- 所有操作包裹在单个撤销块中

**使用方法**：
1. 在排列视图中选中媒体项（点击选中；Ctrl/Cmd 多选）
2. 从操作列表中运行脚本
3. 为每个选中项创建一个区域标记

---

### 从选中项目创建区域标记

**文件**：`km1341_Selected_Items_to_Regions.lua`

根据用户在排列视图中选中的媒体项（事件块）创建区域标记。适用于**任何项目类型**——音频、MIDI、视频等。

**特性**：
- 适用于任何选中的媒体项类型（音频、MIDI、视频等）
- 若选中多个项目，则创建一个从最早起始到最晚结束的单一区域标记
- 使用第一个选中项的 Take 名称作为区域标签（回退到 `Region`）
- 所有操作包裹在单个撤销块中

**使用方法**：
1. 在排列视图中选中媒体项（点击选中；Ctrl/Cmd 多选）
2. 从操作列表中运行脚本
3. 创建一个覆盖选中项时间范围的区域标记

---

### 区域标记吸附至选中事件

**文件**：`km1341_Snap_Region_to_Item.lua`

将所有与选中媒体项重叠的区域标记调整为该事件的时间范围。

**特性**：
- 查找所有与选中项重叠的区域标记
- 将重叠区域调整为与事件完全一致的时间范围
- 所有操作包裹在单个撤销块中

**使用方法**：
1. 在排列视图中选中一个媒体项
2. 从操作列表中运行脚本
3. 所有重叠的区域标记将吸附至该事件的边界

---

### 打开渲染界面（区域渲染矩阵）

**文件**：`km1341_Render_Selected_Tracks.lua`

打开渲染对话框，渲染范围自动设置为所有项目区域。在对话框中设置源为**区域渲染矩阵 - 经由总线**，即可仅渲染矩阵中启用的区域。

**特性**：
- 自动将渲染范围设置为所有项目区域
- 打开渲染对话框供配置源、格式和参数
- 通过区域渲染矩阵控制哪些区域通过总线渲染

**使用方法**：
1. 从操作列表中运行脚本
2. 在渲染对话框中，设置源为 **区域渲染矩阵 - 经由总线**
3. 点击 **矩阵...** 配置要渲染的区域
4. 设置输出格式和参数
5. 点击 **渲染**

## 提示

- 在 **标记/区域管理器**（`Alt+M`）中查看所有区域
- 所有操作均支持**撤销**（`Ctrl+Z` / `Cmd+Z`）
